## Mechanism

In proof-of-work networks, the price of the token and the security of the network are linked. A
higher price finances a larger security budget through block rewards and fees, which attracts
hashrate; more security makes the network more reliable and so raises its value for use and as a
reserve. The relation is reflexive: price, security and acceptance support one another.

Users value not only the existence of the network but also its resistance to attacks: a proof-of-work
token is anchored not only to its transactional use but also to the economic robustness of its
consensus. Theoretical work shows that several equilibria can exist: the same technology can sustain
very different levels of price and security depending on expectations.

## Prediction

Token price and network security support each other: a higher price finances a larger security
budget through block rewards and fees, which attracts hashrate, and more security raises the
network's reliability and so its value for use and as a reserve. The same technology can sustain
very different levels of price and security depending on expectations. The mechanism is more
plausible for large proof-of-work networks than for small ones, and the relation can be blurred by
pure speculation, bubbles and changes in the cost of energy.

## What would refute it

- No relation between hashrate, or the security budget, and token value in proof-of-work networks.
- Price rises that do not attract hashrate, or increases in security that leave the value of the
  token unaffected.
- A single level of price and security for a given technology, insensitive to shifts in expectations.
