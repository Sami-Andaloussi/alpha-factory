# Strategies

One folder per strategy drawn from a theory of the [bank](../bank/), named after its card:
`<theory id>-<nn>-<slug>`. Each holds its written trail, in the order the
[runbook](../RUNBOOK.md) writes it: `reasoning.md`, `card.yaml` (committed alone, before any
code), `build-plan.md`, `strategy.py`, `report.ipynb` (the battery's run, with its outputs) and
`verdict.md`. A rejected strategy stays here with its verdict. The [status board](../STATUS.md)
lists them all with the gate each reached.
